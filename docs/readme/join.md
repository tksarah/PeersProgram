# Join the Astar Peers Program

The Astar Peers Program welcomes community members who want to support the decentralization of Astar Network while gaining practical experience in Linux and blockchain infrastructure.

Participation is open to applicants from any region. Some places are prioritized to improve the geographic diversity of the network.

## Season 3.1 Recruitment

Applications for Season 3.1 are now open.

> **Application Deadline:** August 31, 2026, at 23:59 UTC

Applications submitted after the deadline may not be considered.

## Who Can Apply?

You may apply if you:

- Have basic experience using Linux
- Can prepare and maintain a supported machine
- Can run an Astar archive node
- Can connect the node to Polkadot Telemetry
- Can operate the node with no major interruptions and aim for at least 80% uptime
- Are willing to participate for the relevant program season

For detailed hardware and software conditions, see [Machine and Technical Requirements](./requirements.md).

## Application and Selection Process

1. **Review the program information**  
   Read the program overview, technical requirements, operating rules, and reward policy.

2. **Confirm your environment**  
   Make sure you can prepare a suitable machine, storage, internet connection, and Linux environment.

3. **Submit your application**  
   Use the official application form or instructions announced for the relevant season.

4. **Program review**  
   The program administrator reviews applicants based on eligibility, regional priorities, and the number of available places.

5. **Selection and onboarding**  
   Selected participants receive the information needed to prepare, register, and begin operating their nodes.

6. **Begin node operation**  
   Participants run an archive node, connect it to Polkadot Telemetry, and maintain it throughout the season.
