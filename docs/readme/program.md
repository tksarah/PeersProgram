# Astar Peers Program

## Empowering Astar Through Decentralization

Decentralization is one of the core values of Astar Network.

It is more than an ideal. It is the foundation of a resilient, efficient, and sustainable network. When nodes are distributed across more regions and operated by a wider range of participants, Astar becomes stronger, fairer, and more dependable.

The Astar Peers Program turns this principle into practical action. By bringing together community members around the world, the program helps Astar grow into a truly global and sustainable network.

## Our Objectives

### 1. Strengthen the Decentralization of Astar Network

The program expands community-operated nodes across different parts of the world. By encouraging participation from diverse regions, it aims to improve the resilience and long-term sustainability of Astar Network.

### 2. Develop Future Technical Contributors

The program also helps participants build practical technical skills.

An individual node may appear to be a small contribution. Together, however, these nodes form an important part of the Astar ecosystem. Through hands-on operation, participants learn how their own work contributes to a larger decentralized network.

Blockchain nodes are often expected to run on high-performance, highly available infrastructure. The Astar Peers Program instead encourages participants to operate archive nodes on relatively modest machines. This makes node operation more accessible while providing valuable experience with Linux and blockchain infrastructure.

## How the Program Works

1. Community members apply for a program season.
2. Selected participants prepare a supported machine and run an Astar archive node.
3. Each node is connected to Polkadot Telemetry and operated on an ongoing basis.
4. Node activity is reviewed, and eligible participants receive a monthly reward in ASTR.

## Priority Regions

Participation is open worldwide. The program gives particular attention to regions where greater infrastructure diversity can strengthen the network:

- South America
- Africa
- West Asia
- Southeast Asia — partially achieved during Seasons 1 and 2
- Australia — partially achieved during Seasons 1 and 2
